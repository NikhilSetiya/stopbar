# Security policy

Countersign is security infrastructure. Please report vulnerabilities privately via
GitHub Security Advisories ("Report a vulnerability" on the Security tab). Do not open public issues.

We aim to acknowledge within 72 hours and to publish a fix and advisory within 30 days for confirmed issues.

**Status:** pre-alpha. Not audited. Do not protect production funds with it yet.
Advisory mode provides no protection; only gatekeeper and co-signer modes enforce decisions (see docs/HLD.md §3).
